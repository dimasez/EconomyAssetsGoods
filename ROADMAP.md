# 1. North Star

Построить, теоретически обосновать, внешне верифицировать и эмпирически проверить **архитектуру когнитивного обучения экономике**, а затем превратить её в научный корпус, образовательную методологию, систему заданий / проектов и канонический материал школы мышления.

Главная формула:

> **Экономика — среда; модель — инструмент; мышление — результат.**

Рабочая мета-траектория:

`реальность → различение → понятие → модель → система → измерение → решение → действие → обратная связь`

После интеграции линии О.Р. Чепьюк сохраняется более высокий нормативный горизонт — субъектная позиция, но субъектность **не выводится автоматически** из когнитивных операций.

# 2. Каноническая экономико-системная линия

Текущая рабочая архитектура:

`объект → ресурс → актив → конфигурация системы → способность системы → процесс → эффект → ценность`

Инженерный контур:

`требуемый эффект → функция → требуемая способность`

Операционный контур:

`фактическая способность → процесс → фактический эффект`

Зафиксированы ключевые различения:

- благо ≠ актив;
- ресурс ≠ актив;
- актив ≠ способность;
- способность ≠ процесс;
- процесс ≠ эффект;
- продукт ≠ эффект ≠ ценность ≠ цена;
- функция ≠ способность ≠ процесс;
- capability — эмерджентное свойство конфигурации системы.

➡️ **NEXT B3. Контрастивный / swap test.**

Минимальная пара:

`благо ↔ актив`.

`выручка ↔ прибыль`.

Контроль:

- одинаковый объект;
- одинаковая информация;
- максимально одинаковая задача;
- различается категориальная рамка.

Измерять:

- самостоятельно поставленные вопросы;
- выделенные сущности / отношения;
- границы системы;
- выбранные критерии и показатели;
- типы ошибок;
- решения и обоснования.

# 7. Milestones

## Milestone A — Activity-theory risk resolved

Готово, когда:

- прочитаны ключевые первоисточники Гальперина / Талызиной / Давыдова;
- ясно, существует ли уже механизм `структура понятия → действие`;
- research gap переписан с учётом результата.

## Milestone B — Category mapping protocol formalized

Готово, когда:

- процедура аргументных мест записана пошагово;
- операции маркируются Н / Р / П / Пед;
- есть критерий индивидуации операции;
- есть минимум 5–7 формализованных категорий.

## Milestone C — Mapping is reproducible

Готово, когда:

- проведён blind derivation;
- достигнута приемлемая межэкспертная согласованность либо показано, почему её нет;
- уточнён validation protocol.

## Milestone D — Contrastive prediction exists

Готово, когда:

- минимум одна пара категорий даёт заранее сформулированные различающие predictions;
- задача контролирует формулировку и репрезентацию;
- есть ясные falsifiers.

## Milestone E — Article 1 draft

Только после A–D:

- финальный research gap;
- 8–12 опорных источников;
- 4–6 propositions;
- 3–5 проверяемых hypotheses;
- полный draft в лимите около 40 000 знаков.

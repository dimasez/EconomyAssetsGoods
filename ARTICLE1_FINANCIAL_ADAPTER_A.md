## Appendix A — Financial Adapter

**Связанный CORE:** `ARTICLE1_CODING_MATRIX.md` / `ARTICLE1_CODING_MANUAL.md`, v0.7.3.

# 1. Назначение

Этот файл **не является частью frozen CORE** и не определяет архитектуру экономического моделирования.

CORE отвечает на вопросы:

- что является объектом оценки;
- к какой системе относится показатель;
- что показатель означает;
- какие величины и периоды используются;
- прослеживается ли расчёт;
- соответствует ли он заявленному экономическому смыслу;
- предъявлены ли основания;
- с чем сравнивается результат.

Financial Adapter используется только как дополнительный предметный модуль, когда исследователь хочет описать техническую форму конкретного финансового показателя.

> **Воспроизводимость специального расчёта ≠ экономическая корректность модели в целом.**

Adapter не меняет `Н / И / О / К / С` и не создаёт новых CORE-дефицитов.

---

# 2. Общий протокол

Для любого финансового показателя дополнительно записать:

1. название показателя так, как его называют авторы продукта;
2. объект: проект / компания / продукт / вложение / иной объект;
3. числитель / входящие потоки / база;
4. знаменатель / ставка / горизонт, если применимо;
5. временную размерность входящих величин;
6. предъявленный метод расчёта;
7. может ли значение быть воспроизведено по доступному источнику;
8. какие дополнительные допущения потребовались исследователю;
9. согласуется ли технический расчёт с объектом и смыслом, уже определёнными CORE.

Если метод не назван, adapter **не выбирает за авторов «правильную» формулу**, а фиксирует неоднозначность.

# 3. Prototype reference fields

| Показатель | Что дополнительно фиксировать | Чего adapter не предполагает автоматически |
|---|---|---|
| Простая окупаемость / payback | первоначальный outlay; используемый периодический результат / поток; единицы; период; назван ли метод | что EBITDA, прибыль или денежный поток взаимозаменяемы; что любое деление investment/result является экономически корректной окупаемостью проекта |
| ROI | что является return; что является investment / base; период | единственную универсальную формулу ROI |
| NPV | последовательность денежных потоков; первоначальный outlay; даты / периоды; ставка; горизонт; terminal value, если заявлена | восстановление недостающих cash flows или ставки по догадке |
| Рентабельность | тип результата в числителе; база в знаменателе; период | что «рентабельность» без названной базы имеет однозначный смысл |
| EBITDA | как показатель определён / назван в продукте; период | что EBITDA является денежным потоком или проектным приращением |
| FCF / cash flow | какие потоки включены; учтены ли инвестиционные outflows; период | что отсутствие видимого инвестиционного оттока автоматически означает ошибку CORE без понимания структуры источника |

# 4. Правило использования в Corpus A

Для Corpus A Financial Adapter:

- может применяться как **описательный дополнительный слой**;
- не меняет frozen CORE code;
- не используется для «исправления» работ;
- не используется для вывода о когнитивных способностях учащихся;
- не считается валидированным финансовым стандартом.

Если adapter обнаруживает технический вопрос, который CORE не ловит (например, неопределённый состав cash flow), случай записывается в Issue Log и обсуждается только после Corpus A.

---

# 5. Зачем adapter вынесен из CORE

Экономическая модель проекта может оценивать решение через денежные и неденежные эффекты: снижение затрат, экономию времени, рост производительности, снижение риска, высвобождение мощности, предотвращённый ущерб и др.

Поэтому:

> **CORE описывает структуру экономического моделирования; Financial Adapter — лишь один сменный модуль специальной количественной техники.**

Этот принцип защищает статью №1 от сужения до финансовой проверки школьных бизнес-планов.

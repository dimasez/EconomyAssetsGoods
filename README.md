# EconomyAssetsGoods

Методологический проект по теме **«актив — благо — ценность»** в рамках курса «Основы экономики и бизнеса» и более широкой архитектуры когнитивного обучения экономике.

## Статус

**v0.1 — методологическая записка / рабочая модель**

Проект фиксирует текущую согласованную версию понятийной архитектуры и историю её изменений. Цель — не просто написать текст, а построить устойчивую модель, которую можно критиковать, уточнять, применять в курсе и затем превратить в канонический методический материал.

## Центральный вопрос

Что меняется в экономическом мышлении, если начинать не с категории «благо», а с более общей онтологии:

`реальность → объект → система / субъект → экономическое отношение → процесс → эффект → ценность → измерение`?

## Текущая позиция

Мы **не заменяем благо активом**.

Мы различаем:

- **объект** — единицу реальности, выделяемую в модели;
- **благо** — экономический статус объекта в отношении к потребности, предпочтениям и выбору субъекта;
- **ресурс** — объект, который система способна использовать;
- **актив** — контролируемый системой экономический ресурс / право с потенциалом будущих экономических выгод;
- **эффект** — изменение состояния системы;
- **ценность** — оценку значимости этого изменения для использующей системы.

Благо и актив не являются конкурирующими сущностями и не находятся в отношении «род–вид». Один и тот же объект может одновременно иметь несколько экономических статусов в разных моделях и относительно разных систем.

## Педагогическая гипотеза

Оптика через благо преимущественно тренирует **выбор из существующих альтернатив**.

Оптика через актив преимущественно тренирует **создание, преобразование и управление**.

Рабочая четверка ролей:

1. **Потребитель:** что выбрать?
2. **Предприниматель:** что создать?
3. **Управленец:** как организовать преобразование?
4. **Собственник / инвестор:** какую отдачу дают активы?

## Рабочая формула экономики

> **Экономика — язык преобразования ограниченных ресурсов в ценимые изменения состояния систем.**

Это рабочая формулировка, а не окончательное академическое определение.

## Файлы проекта

- [MASTER.md](MASTER.md) — каноническая текущая версия модели;
- [STRUCTURE.md](STRUCTURE.md) — структура будущего методологического текста;
- [DRAFT.md](DRAFT.md) — растущий черновик;
- [DECISIONS.md](DECISIONS.md) — журнал принятых и отвергнутых решений.

Позже при необходимости добавятся:

- `DEFINITIONS.md` — расширенный словарь;
- `SOURCES.md` — источники и разметка «источник / интерпретация / наша модель / гипотеза»;
- `PROGRESS.md` — рабочий трекер при увеличении объёма проекта.

## Протокол работы

Перед существенной сессией:

`MASTER → STRUCTURE → DECISIONS → текущий фрагмент DRAFT`

После существенной сессии:

`DRAFT → DECISIONS → MASTER (если модель изменилась)`

Эпистемические статусы:

- **[ИСТОЧНИК]** — утверждение внешнего автора, стандарта или школы;
- **[ИНТЕРПРЕТАЦИЯ]** — наше прочтение источника;
- **[НАША МОДЕЛЬ]** — принятое методологическое решение;
- **[ГИПОТЕЗА]** — положение, требующее проверки.
